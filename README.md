### Salary Trend Predictive Model 📊
This project provides a clear, data-driven approach to predicting employee salaries based on their years of experience using Simple Linear Regression.
Overview
This project provides a clear, data-driven approach to predicting employee salaries based on their years of experience using Simple Linear Regression. It demonstrates the complete end-to-end workflow of a machine learning model, from data preprocessing to performance evaluation and visualization.

---

### Project Highlights

Utilized Pandas and NumPy to clean and structure historical salary data.

Implemented a Scikit-Learn Linear Regression model to identify the underlying relationship between tenure and compensation.

Split the dataset into training and testing sets (80/20) to ensure the model performs accurately on unseen data.

Used Matplotlib to generate a high-clarity regression plot, showcasing the predictive accuracy against actual test data.

---

### Model Performance:

The model achieves an R2 score of [0.9711], indicating a high level of accuracy in capturing the variance in the salary dataset.
